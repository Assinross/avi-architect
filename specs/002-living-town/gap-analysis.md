# Gap analysis: 001 "Новая долина" → 002 "Первый живой город"

Цель 2.0 - постоянный живой город, в котором игрок видит последствия своих решений: заказчик просит дом, игрок проектирует его, город заселяется, жители реагируют, открывается следующий заказ.

## Что уже работает в 001

| Возможность | Где | Состояние |
| --- | --- | --- |
| Модель здания метрами | `src/model.ts` (`BuildingModel`, `Wall`, `Opening`) | Готово, источник для 2D и 3D |
| Проверка проекта: площадь, дверь, окна, бюджет | `issues`, `area`, `cost` | Готово |
| Смета и цены | `prices` (12/45/30/4) | Готово |
| История изменений | `History` | Готово |
| 2D-планировщик | `src/editor.ts` | Готово |
| 3D-объём здания | `src/rendering/building.ts` | Готово |
| Долина: река, мост, ратуша, площадь, деревья | `src/rendering/land.ts`, `town.ts` | Готово |
| Два участка и два заказа | `lots` в `land.ts`, `rules` + `copy` в `main.ts` | Жёстко зашито |
| Три жителя с маршрутами | `rendering.ts` (`resident`, `Citizen`) | Ходят, но не реагируют |
| Сохранение с версией | `src/storage.ts`, конверт v1 | Готово для двух зданий |
| Тесты и CI Pages | `tests/*`, `.github/workflows/pages.yml` | Готово |

## Разрывы относительно 2.0

| # | Разрыв | Следствие для игрока | Чем закрывает 002 |
| --- | --- | --- | --- |
| G1 | Мир не город: два участка, фиксированная очередь | Нет ощущения места, некуда расти | `TownState` с 4 участками (3 застраиваемых, 1 резерв), дорожки от площади к каждому |
| G2 | Миссии зашиты в код: `copy` и `rules` в `main.ts`, `currentQuest` - жёсткая цепочка | Новый заказ = правка кода | `src/missions.ts` - чистые данные, порядок через `requires` |
| G3 | Нет состояния города отдельно от зданий | Нельзя показать заселение, журнал, реакции | Состояние города: участки, активный заказ, журнал завершений, награды |
| G4 | NPC не реагируют на постройку | Строительство не ощущается событием | Реакция: житель идёт к двери, реплика, свет в окне, член семьи "вселяется" |
| G5 | Нет анимации строительства | Дом появляется мгновенно | Появление дома: рост стен, крыша, пыль, ~2 с; только на переходе, не при загрузке |
| G6 | Визуал: стиль есть, но город пустоват | Красиво, но не "уютно" | Мягкий свет и контактные тени, выразительные крыши, окна с ящиками цветов, дорожки, лампы, заборы, кусты, детали |
| G7 | Сохранение v1 описывает только два здания | Новые сущности сломают старые сохранения | Конверт v2 + миграция v1 без потери дома Эммы и пекарни |
| G8 | Бюджет виден только числом в карточке | Непонятно, сколько осталось | Панель бюджета: шкала расхода, площадь, окна, дверь - обновляется при правке |

## Что сознательно остаётся за рамками 002

- Новые типы зданий, кроме уже существующих `home` и `bakery`.
- Многоэтажность, скатные крыши произвольной формы, интерьеры.
- Сложная экономика: зарплаты, налоги, дефицит, проигрыш. Наказаний нет.
- Сервер, аккаунты, сетевые сохранения, платные API, реклама.
- Главы 3-5 из `docs/roadmap.md` (магазины, инженерные сети, рельеф, эпохи).
- Свободное рисование стен вне метровой сетки.

## Риски

| Риск | Смягчение |
| --- | --- |
| Переезд `buildings` с ключей `purpose` на ключи участков ломает 001-тесты | Миграция v1→v2 в `storage.ts` покрыта unit-тестами; старые сценарии сохраняются как регрессия |
| Анимация строительства ломает e2e (элементы двигаются) | Анимация только визуальная, состояние готово сразу; e2e ждёт по состоянию, а не по кадру |
| Визуальные правки ухудшают производительность на слабых устройствах | Качество `low` отключает тени, анимация строительства и часть декора |
| Сенсорное управление конфликтует с выбором участка | Порог движения пальца сохраняется, тап по кнопке HUD не попадает в сцену |

# 004 — Образовательное ядро: «Книга архитектора» и открытия между миссиями

**Feature:** `004-architecture-education`  
**Состояние:** первая версия **реализована** в `main` (2026-11-22); будущие модули отдельно помечены как TODO.  
**Возрастная цель:** ориентировочно 8–12 лет; задания должны быть понятны при самостоятельном чтении или совместно со взрослым.

## Цель

Не только познакомить ребёнка с управлением редактором, а дать начальные способы **архитектурного мышления**: замечать потребности людей, выбирать планировку, понимать размеры и стоимость, видеть взаимодействие конструкции, света, красоты и окружающей среды, узнавать известные сооружения.

Формула обучения: **«потребность заказчика → проект → эксперимент → проверка → открытие об архитектуре»**. Факты должны быть короткими, интересными и корректными. Вопросы и дополнительное чтение добровольны: они не блокируют карьеру и не карают за ошибку.

## User Stories / критерии приёмки

### US-01. Учебная цель в карьерной мастерской — реализовано

**Как игрок** я хочу перед проектированием понять, что именно изучаю, и получить маленький эксперимент для самостоятельной проверки.

**Acceptance:**
1. При открытии `workshop.html?mode=career&quest=home` показаны **план, площадь и свет**; есть подсказка сравнить 4×3 м и 6×2 м по площади/периметру.
2. В задании `bakery` цель касается **назначения помещений, входа, окон и перегородок**.
3. В `landmark` цель касается **этажей, лестниц, перекрытий и опор**.
4. В свободной мастерской доступен необязательный эксперимент без учебных блокировок.
5. **Практический навык засчитывается только по завершённому заказу в городе**, а не по прочтению карточки.

**Реализация:** `src/education.ts:lessons`, `src/workshop.js` и `src/builder-policy.ts`.

### US-02. История на переходе между миссиями — реализовано

**Как игрок** после сдачи проекта я хочу увидеть красивую карточку, связывающую моё строительство с настоящим архитектурным достижением.

**Acceptance:**
1. После **дома Эммы** на экране завершения заказа появляется история **Антони Гауди и Дома Бальо** — реконструкция и необычные фасады/окна.
2. После **пекарни Льва** появляется история **Владимира Шухова и Шуховской башни** — прочность и лёгкая решётчатая конструкция.
3. После публикации **дома Ники** появляется история **Фрэнка Ллойда Райта и Дома над водопадом** — выступающие террасы, консольная идея и связь с природой.
4. Карточка содержит **фотографию**, краткий вводный текст и возможность открыть полную историю; есть явный возврат к игре. Пропуск чтения **не препятствует следующему шагу**.
5. История Ники показывается при возвращении из редактора в город, поэтому не требует отдельного четвёртого заказа.

**Реализация:** `src/main.ts` (finished/discovery), `src/education.ts:featuredMarkup`, `src/workshop.js` (возврат после сдачи).

### US-03. «Книга архитектора» для чтения в любое время — реализовано

**Как игрок** я хочу в любой момент открыть короткие сведения о зданиях, даже если они не связаны с текущей миссией.

**Acceptance:**
1. Книга открывается из **главного меню**, из **городского HUD**, а также из **карьерной и свободной мастерской**.
2. Каталог содержит **пять историй**: Гауди/Дом Бальо, Шухов/башня, Райт/Дом над водопадом, **Пантеон в Риме** (окулюс) и **Филиппо Брунеллески/купол флорентийского собора**.
3. **Все пять историй доступны сразу**, в любом порядке, без привязки к прогрессу карьеры; две последние намеренно являются независимыми открытиями.
4. В карточке есть **название, место, период, фотография с доступным alt, краткий факт, идея для эксперимента**, ссылка на источник фактов и атрибуция фотографии.
5. Материал без посторонней рекламы и не требует аккаунта, сервера, платного API или микрофона.

**Реализация:** `src/education.ts:stories,bookMarkup,storyMarkup`, `src/main.ts`, `src/workshop.js`.

### US-04. Необязательная проверка знаний — реализовано

**Как ребёнок** я могу ответить на один небольшой вопрос по прочитанной истории и получить пояснение.

**Acceptance:**
1. Для каждой из пяти карточек предусмотрен **один вопрос и два варианта ответа**.
2. Ошибка показывает спокойную подсказку с возможностью попробовать ещё раз, без штрафа и блокировки.
3. Правильный ответ раскрывает объяснение; книга отмечает историю как изученную.
4. Счётчик **практических навыков** выводится из завершённых заказов `home`, `bakery`, `landmark` (0–3); счётчик **ответов** — из правильных решений по пяти историям (0–5). Эти прогрессы не подменяют друг друга.

**Реализация:** `src/education.ts:checkAnswer,skillCount,recordLearning`.

### US-05. Локальные изображения, авторские права и сохранение прогресса — реализовано

**Acceptance:**
1. В репозитории находятся **5 локальных JPG** в `public/architecture/` и **5 локальных SVG** в качестве запасных иллюстраций.
2. Картинка загружается **из той же сборки игры**, а не по горячей внешней ссылке. При ошибке JPG автоматически подставляется соответствующий SVG.
3. Для каждой фотографии указаны **имя автора, лицензия, ссылка на конкретную страницу файла Wikimedia Commons**. Реестр: `public/architecture/CREDITS.md` и `public/architecture/ASSET_REGISTER.csv`; информация также видна в карточке.
4. Исторические факты снабжены ссылками на профильный источник. **Лицензию проверять для каждого нового изображения отдельно**, не переносить лицензию на весь сайт.
5. Списки прочитанных `read` и правильно отвеченных `solved` хранятся в отдельном ключе `avi-architect.learning.v1`; при новой игре/сбросе прогресс обучения очищается.
6. Повреждённые данные прогресса не должны ломать открытие книги; недоступность хранилища не мешает чтению. **Поддержка старых версий игровых сохранений не требуется.**
7. Сохранение картинок **в репозитории** не означает автоматической работы всего сайта без интернета: офлайн-режим/PWA сейчас **не реализован**.

**Реализация:** `src/education.ts:normalizeLearning,readLearning,resetLearning,installPhotoFallback`, статические ресурсы `public/architecture/`.

**Важно для достоверности:** не приписывать римский Пантеон Витрувию. Не считать декоративные опоры игрой в реальный расчёт прочности. Лестницы 1×1/1×2 м — игровые условности, а не реальные нормы. Нависающий этаж сам по себе не мансарда.

## Не-функциональные требования

- Контент читается небольшими частями (приблизительно 30–90 секунд на карточку), без обязательного заучивания дат.
- Иллюстрация имеет текстовую альтернативу; все вопросы и действия — обычные кнопки, доступные для клавиатуры.
- Не требуются платные сервисы и сторонние runtime-запросы к картинкам.
- Не блокировать карьеру информационным экраном или викториной.
- Публикация с основным приложением через Vite/GitHub Pages.

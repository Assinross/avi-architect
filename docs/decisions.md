# Решения первой главы

- Статическая сборка Vite и Three.js позволяет разместить долину с её ресурсами в одном каталоге GitHub Pages. Игровой процесс и сохранение выполняются в браузере.
- Ортогональная сетка с прямоугольным контуром даёт однозначные площадь, крышу и цену. Первые задания допускают разные решения, включая несколько планов одинаковой площади.
- Смещение проёма отсчитывается от первого конца стены. Это сохраняет направление при построении SVG-плана и фасада.
- Цвета и декор относятся к отображению. Геометрия переживает смену темы и переход между видами.
- Город использует два именованных участка с фиксированной очередью. Этого достаточно для первой главы. Движение жителей можно восстановить на известных маршрутах после загрузки.
- Локальный JSON хранит только игровые данные. Перед чтением и записью проверяются инварианты города. Пользователь может начать заново через запрос подтверждения.


## Единая система проектирования (005)

- Планировщик — один модуль: `src/workshop.js` и `src/multistorey.ts` для свободного и карьерного режимов. Доступность инструментов и требования к заказу определяются исключительно `src/builder-policy.ts`.
- Свободная мастерская: все инструменты и постоянно активный 3D-просмотр. Карьера: последовательные открытия (Эмма — контур/проёмы; Лев — перегородки; Ника — несколько этажей и лестницы), бюджет, обязательная проверка, 3D-просмотр по запросу.
- В городе сохраняется полный поэтажный план каждого заказа и используется тот же геометрический движок. Отдельный редактор первой главы удаляется из игрового маршрута.
- В стадии активной разработки не обеспечивается совместимость пользовательских сохранений: формат может изменяться со сбросом прогресса. **Не добавлять миграции версий, обратные декодеры или тесты совместимости**, если это не запрошено отдельно.
